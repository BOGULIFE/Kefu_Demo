### 2.1 关键路径

1. 查看昨日：进入P01 → 加载昨日记录 → 阅读日期、状态、排名问题及对应话术 → 按需展开长话术。昨日未完成时展示昨日真实状态，不回退前天内容。
2. 回查某日：P01历史入口 → P02默认昨日 → 单日选择器/日期列表选日 → 详情加载 → 查看保存内容 → 返回数据统计页，P01按当前北京时间重新计算昨日。
3. 异常恢复：读取失败 → 原位置重试；生成失败 → 查看状态、稍后刷新，系统自行重试，用户刷新不调用AI。
4. 组织/身份变化：立即撤下旧范围内容 → 新范围校验、加载 → 新组织内容或不可访问反馈，旧响应不能覆盖。

### 2.2 信息优先级

组织上下文 → 页面/模块标题及所属日期 → 生成状态、超时说明 → 问题排名与问题 → 对应实际回复及适用条件 → 生成完成时间及统计说明。日期不能隐藏在提示气泡内；生成时间不能代替所属日期。历史页日期导航和选中日期标题必须一致。

## 5. 状态、联动与文案

### 5.1 统一状态表（UX22）

UX22对应F01、F02、F06—F08，主要关联AC18—AC24、AC27—AC31。业务生成状态与查询过程分开表达：已保存成功记录查询失败，不得改写成生成失败。状态同时有文字及必要图标，颜色只辅助。

| 场景/触发 | 视觉表现 | 可用操作 | 数据保留 | 恢复路径 |
| --- | --- | --- | --- | --- |
| 首次进入/切换日期加载 | 目标日期、轻量骨架和「加载中…」；不显示旧问题 | 返回、历史入口及合法日期导航可用；同次刷新禁用 | 不跨日期保留详情 | 最新请求成功显示完整结果，失败显示读取错误 |
| 同组织同日刷新中 | 原结果上方「刷新中…」，不整卡闪白 | 返回/日期导航；刷新暂禁用 | 同日结果可保留，状态与话术保持同一版本 | 成功整体替换；失败加上次读取标识 |
| 待生成 | 中性时钟图标、日期、「待生成」 | 刷新、历史、返回 | 不展示问题占位为真实结果 | 系统处理后刷新查看 |
| 生成中 | 处理图标和「生成中」，无伪百分比 | 刷新、历史、返回 | 不显示未保存部分结果 | 系统完成后刷新查看，无定时轮询 |
| 成功 | 「已生成」、完成时间、实际数量结果 | 阅读、展开、刷新、历史/返回 | 同日保存内容稳定 | 查看历史不重新生成 |
| 无数据 | 中性空态图标、「当日暂无可总结的咨询」、所属日期及完成时间 | 刷新、历史/日期切换、返回 | 保存当日无数据状态；不显示5条空项或数字0代替问题 | 查阅其他日期 |
| 上线当天，无可回查日 | 「首份总结将于上线次日02:00前提供」，可补充实际首份日期 | 刷新、返回；P01历史入口可进入空历史页 | 不展示上线前日期；P02选择器和分页不可用 | 次日查询首份 |
| 生成失败 | 错误图标、「生成失败，请稍后刷新查看」，保留日期 | 刷新、历史/换日、返回；无重新生成按钮 | 无已保存完成结果时不显示部分内容，不拿前天替代 | 后台自动重试，刷新只查询 |
| 对应日期D+1日02:00已到仍未完成 | 真实状态旁附「未按计划完成」，不只转圈 | 刷新、历史/换日、返回 | 所属日期不变，不冒充成功/无咨询 | 系统补齐后按原日展示；不能宣传按时完成 |
| 首次查询失败 | 「加载失败，请重试」，不标成当日无咨询或生成失败 | 原位置「重试」、返回及合法日期导航 | 不伪造状态、完成时间或问题 | 重试读取同一日期 |
| 同日刷新失败，有旧结果 | 顶部错误提示「更新失败，当前为上次读取结果」 | 重试、阅读原结果、换日/返回 | 仅同组织同日授权结果可保留；日期及状态不混版本 | 再次刷新成功后移除错误标识 |
| 日期列表翻页失败 | 列表区域「日期列表加载失败，请重试」 | 列表重试、原选择/返回 | 恢复原成功页号和日期，不假装已切页 | 重试目标页 |
| 非法日期输入 | 字段错误边框、错误文字，可选日期范围 | 更正、取消、其他合法日期导航 | 上次有效日期及结果仍明确显示 | 更正提交或恢复原值 |
| 单个话术缺失 | 问题排名保留，话术区中性「暂无可归纳的客服回复」 | 阅读其他项、刷新/返回 | 不影响该日成功状态，不生成替代话术 | 同日结果按保存内容显示 |
| 组织切换 | 撤下旧内容，新组织加载占位 | 有权限的新组织导航、返回 | 不保留旧组织列表、话术、完成时间及在途结果 | 新组织校验成功后显示 |
| 无权限/身份失效/不可访问 | 整个受限区域显示通用不可访问反馈，不泄露记录存在与否 | 返回可访问页面；身份失效沿用现有登录恢复 | 立即撤下越权缓存，禁止保留上次读取结果 | 恢复身份/权限后重新查询 |

02:00提示按目标所属日期的次日计算，历史失败记录同样适用。成功或无数据完成后展示其真实完成时间，不再以仍在处理的提示覆盖结果；迟于目标时点完成也不写「按时完成」。

| 改日期/组织 → 旧响应 | 日期变更撤下旧详情；组织变更撤下全部旧范围数据 | 仅最新日期、当前组织、有权限响应生效 |
| 权限失效 → 全部内容 | 撤下内容、禁用受限操作，保留安全返回 | 旧缓存保留规则在无权限时失效 |
| 跨日 → 昨日及上限 | 再次进入/查询/刷新重新计算北京时间昨日与合法范围 | P01切新昨日；P02保留仍合法当前日，页码按新范围定位 |
| 展开话术 → 阅读状态 | 一项展开不影响其他项，收起回到同项 | 同日刷新可保留展开，切日切组织重置，不改结果排序 |

### 5.4 口径说明内容与位置（UX25）

UX25对应F03—F06及AC05—AC09、AC13—AC17、AC25。两页都可通过「统计说明」展开以下规则，不能只用状态色或一个无文字图标表达：

- 统计范围为当前组织全部人工客服与用户聊天文本，不限当前账号本人接待；不包含工单、图片、语音和机器人数据。
- 按北京时间消息发送时间取所属日00:00（含）至次日00:00（不含）；跨日会话只看当日文本，不按接待开始时间归日，不跨日补全回复。
- 同类问题按涉及会话数排序，同会话同类当日只计1次；一个会话可涉及多类，转接不重复计，同份结果排序保持稳定。最多5类、不足不补齐；不展示合计数。
- 话术仅归纳该日客服实际回复，保留适用条件；不是知识库补充答案。没有对应实际回复时按缺失状态显示。
- 每日凌晨自动处理前一自然日，次日02:00前可查看；刷新仅查询。首份覆盖上线当天完整自然日，包括上线时刻之前的当天文本；不补算上线前日期。

产品页面使用简短业务说明，不显示模型提示词、任务ID、SQL、接口路径、测试开关或推理过程。上述说明不等同于新增统计指标。

### 6.2 桌面适配与阅读（UX27）

- 建议以1440px桌面为主稿，校验1280px及1024px可用性。内容区随侧栏伸缩，卡片外边距建议24px，低宽度可16px。

- 问题标题允许换行；话术保留段落、条件列表，长英文/账号示例强制断行避免横向撑破。所属日期与排名使用清晰、稳定宽度，不新增频次数字。

### 6.3 键盘与辅助阅读（UX28）

- 日期字段有可见标签及范围说明，错误通过文字和关联描述反馈；提交后的详情日期与输入草稿区别明确。
- Tab顺序遵循返回/页头操作 → 日期选择 → 日期列表/分页 → 详情展开/说明；Enter/Space可激活按钮，日期弹层Esc可关闭并返回原焦点。
- 日期选中项同时有背景、边框和可访问选中状态；禁用控件有原因说明，不能只依靠降低透明度。
- 普通正文与背景对比至少4.5:1，大字号文本至少3:1；交互焦点清晰可见，不通过颜色区分唯一信息。图标按钮有名称。
- 查询反馈可通过礼貌状态播报更新；错误与字段关联；加载不将焦点抢走。翻页后焦点移至新页首个选中日期，话术展开后保留触发焦点；返回页有明确页头定位。
- 空态不使用与真实结果完全相同的无字骨架；状态图标配文字。动效为辅助，减少动态偏好下可禁用骨架流动及旋转动画。
