# FR-wenkf-003 每日高频咨询静态原型

直接双击 `FR-wenkf-003-每日高频咨询Demo.html`，无需安装、构建或联网。默认进入数据统计页，先展示完整的「服务数据概览」，包含我的工单、需求待办、结果待反馈、按处理角色四行表格，以及近30天新建工单折线图；「昨日高频咨询」位于整个概览卡片之后。菜单沿用最新截图的「管理与运营」，不另建「运营与管理」菜单。

## 主要操作

- 阅读问题及对应回复话术，第一项可展开全文、收起；「统计说明」展开业务口径。
- 从模块右上角进入历史高频咨询。选择一个日期立即读取；日期列表每页20日，翻页自动选中该页首日；返回后重新查询昨日。
- 日期只允许组织上线日至昨日。错误草稿不替换原结果，支持恢复有效日期；刷新浏览器保留合法选中日和所在页。
- 页面右下角「原型演示」是辅助工具，独立于业务操作。可切换场景，或模拟下一次刷新/翻页失败、后台补齐、跨零点和权限撤销。
- 组织选择可切换右豹与星河服务。切换时旧数据立即撤下，仅当前请求可显示；星河使用独立的订单售后样例及更短的历史范围。
- 刷新只模拟读取，不执行AI生成。生成失败后可在演示工具中「模拟后台自动补齐」，再点业务区刷新观察原日期结果；成功保护操作只演示已保存结果不被失败覆盖。

## 稳定场景入口

在HTML文件名后附加以下查询参数即可定位，也可在演示面板选择；未知scene回到成功场景。参数不是生产接口。

| 参数 | 入口/状态 |
| --- | --- |
| `?scene=success` | 默认Top 5，含两个适用条件和长话术；第5/6名同频，固定保留第5名 |
| `?scene=three` | 实际3类，不补足5条 |
| `?scene=tie` | 固定并列排名，与默认同一保存顺序；不展示频次 |
| `?scene=missing` / `?scene=crossday` | 最后一项无当日可归纳回复；跨日示例不取次日回复 |
| `?scene=history` | 历史默认昨日，36个日期、两页 |
| `?view=history&scene=success&date=2026-11-04` | 直接进入第二页指定日期；可替换为范围内其他单日 |
| `?scene=pending` / `?scene=generating` | 演示北京时间01:20，待生成/生成中 |
| `?scene=empty` | 已完成无咨询，显示真实演示完成时间 |
| `?scene=failed` / `?scene=overdue` | 生成失败/生成中且未按计划完成，均无部分结果 |
| `?scene=first` | 演示11月25日上线当天，暂无可回查日，日期及分页禁用 |
| `?scene=firstNext` | 演示11月26日，上线次日首份，覆盖11月25日完整自然日 |
| `?scene=loading` | 固定查询加载态；通过演示面板切换其他场景退出 |
| `?scene=readError` | 首次读取失败，重试恢复；不伪造生成状态 |
| `?scene=staleError` | 同日刷新失败，保留已读结果并持久提示，重试恢复 |
| `?scene=pageError` | 历史下一次翻页失败，保留原页、原日期，支持列表重试 |
| `?scene=permission` | 无数据统计权限，撤下受限内容，提供安全返回 |
| `?scene=orgRace` | 读取延迟为1.5秒，期间切组织或换日，过期请求被忽略 |
| `?scene=midnight` | 23:59；面板推进时钟后刷新重算昨日和历史上限 |
| `?scene=recovered` | 同一所属日期已在10:20:16补齐，显示实际完成时间 |
| `?scene=protected` | 已完成结果；面板模拟后续任务失败，原结果不变 |
| `?scene=success&view=history&org=b` | 星河服务组织历史，起点11月10日 |
| `?scene=success&view=history&embed=1` | 嵌入模式，隐藏外围导航和演示工具，保留组织、日期、返回和业务操作 |

可组合 `view=history`、合法`date`、`org=a/b`和`embed=1`。非法直达日期显示通用不可访问反馈。URL会记录演示日期与时钟，便于刷新重现；不使用真实系统日期。

## 演示数据与限制

- 默认北京时间：2026-11-25 10:30:00；右豹虚拟上线日2026-10-20，星河2026-11-10。上线当天及上线次日场景另设上线日2026-11-25，不能把这些日期当作生产起点。
- 默认历史：11月24日5类、23日3类、22日无数据、21日失败、20日待生成，其他日期为稳定样例。默认排序依据为内部虚拟会话频次42、31、24、18、12、12，页面只显示前5类，不展示频次或合计。
- 所有问题、条件、时效和回复均为虚拟客服聊天归纳样例，不是右豹正式服务承诺。没有个人真实信息。跨日示例假定当日23:59提问、次日00:01回复，因此当日话术缺失。
- 后台AI归纳、调度、会话去重、数据库唯一约束和权限鉴别均未真实实现；演示在本地模拟交互及结果。内嵌样例可在源文件中查看，不能当作真实权限安全方案。
- 面板里的补齐、权限、时钟变化仅保留在当前页面内；浏览器刷新后按URL场景重新初始化。稳定业务入口和保存样例保持一致，不模拟持久数据库。
- 原统计区域数值来自参考截图的演示重建；其导出、刷新、其他菜单和账号操作明确提示属于原有能力，本需求未实现它们。无新增导出、手动重生成、话术应用、H5或发布功能。
- 独立HTML内嵌CSS和脚本，无CDN、远程字体、图片请求、模块导入或本地fetch依赖。浏览器工具不允许file协议，因此本次使用本地HTTP验证；未用浏览器工具直接验证双击打开。
