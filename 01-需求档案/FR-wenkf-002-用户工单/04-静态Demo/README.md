# FR-wenkf-002 · 用户工单静态UX Demo

双击 [FR-wenkf-002-用户工单Demo.html](./FR-wenkf-002-用户工单Demo.html) 可离线打开，无需安装依赖或联网。它内嵌全部CSS、JS和预置图片。`index.html`为同一实现的开发入口，依赖旁边的`style.css`、`app.js`；修改后运行`python build.py`同步独立文件。

## 演示内容

- 现有“工单处理”统一列表，来源列和来源／归属／状态／关键词组合查询，20条分页。
- 右侧详情抽屉与处理时间线；客服创建和用户提交按来源展示不同内容、状态与操作。
- 用户提交自动指派、无需接收；移交给其他客服后保持处理中。普通客服移交后返回列表并失去查看资格。
- 管理员创建类型及六种表单字段，可增删排序、配置必填和单／多选选项；保存后在H5可选择。
- H5首页双卡片、反馈类型、表单校验、图片／MP4本地选择与预览、成功页、本人记录与处理结果。
- 完结按最新截图保留“已解决／未解决／转需求”、内部处理结论、处理依据／验证记录、面向用户的结果说明；三项文本均必填。H5仅展示公开说明，内部结论及验证信息留在后台。

## 建议体验顺序

1. 顶部选择移动端H5，从“提交工单反馈”选择模板并填写提交。截图和视频是选填，可使用本机演示素材；文件只在本地读取，不发往任何服务器。
2. 切换管理后台，用成功页的工单编号搜索并点击查询，打开新工单详情。
3. 移交或填写三个必填说明后完结；切回H5的“工单记录”查看已完结及公开说明。
4. 管理后台“工单类型配置”可创建新模板，再切H5查看新类型。

顶部深色“静态UX DEMO”栏及“演示设置”属于演示工具。可切管理员／普通客服思雨／晓晓、用户U（10086）／V（10087），以及下一次操作失败、冲突、处理人不可用、响应丢失、上传失败等异常。工具区可重置数据；重置仅影响本Demo。

## 场景深链接

在独立文件名后附查询参数即可，以下路径同样适用于HTTP入口：

| 端 | 参数 |
| --- | --- |
| 后台列表 | `?client=admin&scene=unified-list` |
| 来源查询 | `?client=admin&scene=source-query` |
| 用户详情／移交／完结 | `?client=admin&scene=user-detail`／`transfer`／`finish` |
| 客服工单三种详情 | `?client=admin&scene=legacy-detail`／`legacy-processing`／`legacy-completed` |
| 模板列表／创建 | `?client=admin&scene=templates`／`template-create` |
| 后台异常 | `?client=admin&scene=admin-errors`／`permission`／`empty`／`loading` |
| H5首页／类型／表单 | `?client=h5&scene=home`／`type-select`／`form` |
| 成功／记录／详情 | `?client=h5&scene=submit-success`／`records`／`record-detail`／`completed-detail` |
| H5异常 | `?client=h5&scene=mobile-errors`／`no-types`／`no-records`／`permission` |

斜线后的短场景名替换前一个URL中的`scene`值，不是独立路径。场景也可直接从顶部下拉框选择。`&embed=1`隐藏重复外框供交付中心嵌入，不改变业务规则；已接入共用交付门户，可从根目录 `index.html` 进入FR-wenkf-002。可附`&role=a`或`&role=b`直接演示普通客服。

## 数据与能力边界

- 预置记录采用2026-11-18至20日的模拟数据；新操作时间采用北京时间。无真实用户、工单接口、消息或外部服务。
- 类型、工单及结果尽可能保存在当前浏览器本地；同源标签页可以同步。HTTP与文件直开、不同浏览器或不同设备不共享存储。大附件可能超过本地存储限额，此时仅在当前会话保留，并提示用户；不是服务端附件存储。
- 上传为本地读取加模拟过程；实际选择的图片／视频可预览，格式大小数量按PRD方案校验。预置示例图片为内嵌素材，未伪造真实视频。
- 已有非本次功能（创建客服工单、索取材料、补充记录、旧工单重开等）保留入口并说明原有能力，不重建其未提供的完整流程。旧工单接收可演示状态变化。
- “转需求”仅演示完结分类，不自动创建产品需求。本次不新增通知、SLA或统计口径。
- 原型中的权限、提交幂等、冲突及错误是模拟交互，不代表真实后端安全、并发或上传服务通过验收。
