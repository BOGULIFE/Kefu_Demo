### 5.1 指标展示与说明表

| 指标名称 | 单位 | 必须传达的统计含义 |
| --- | --- | --- |
| 累计接待 | 次 | 当前组织内该客服自2026-10-30起的接待会话次数，与日期筛选无关 |
| 接待会话数 | 次 | 所选日期内按该客服首次开始接待时间归日；同一会话对同一客服计1次，转接涉及客服各计1次 |
| 评价数 | 条 | 所选日期提交、归属该客服的评价；转接评价归最后接待客服 |
| 好评数 | 条 | 4—5星 |
| 中评数 | 条 | 3星 |
| 差评数 | 条 | 1—2星 |
| 创建工单数 | 个 | 本人创建；创建不代表实际接取经手 |
| 处理中工单数 | 个 | 该客服已接取且当前仍由其正在处理；不含待接取、转交、已完结 |
| 已完结工单数 | 个 | 该客服曾实际接取经手、当前已完结的工单；不只统计本人最终完结的工单 |

每日表列顺序：日期 → 接待会话数 → 评价数 → 好评数（4—5星）→ 中评数（3星）→ 差评数（1—2星）→ 创建工单数 → 处理中工单数 → 已完结工单数。

范围接待会话数与历史累计在「全部」下相等属于正常展示，不合并两个区域；切换日期后仍能保持同一结构，帮助用户理解差异。

## 6. 日期选择交互需求表

| UX编号 | 情况 | 操作／表现 | 结果要求 |
| --- | --- | --- | --- |
| UX-T01 | 默认全部 | 全部选中，显示2026-10-30至今日 | 全部不受自定义1年跨度限制 |
| UX-T02 | 快捷日期 | 今日／昨日／近7天点击即查询 | 近7天含今日；更新实际起止日期，日表回第1页 |
| UX-T03 | 自定义编辑 | 显示开始、结束日期和「查询」「取消」；未提交状态明确 | 保留原结果及原生效日期标签，提示「日期尚未生效」，导出暂禁 |
| UX-T04 | 提交自定义 | 合法后点击查询 | 用新范围替换结果，日表回第1页；自定义含首尾日 |
| UX-T05 | 取消编辑 | 点击取消 | 恢复已生效选项、日期和导出可用性 |
| UX-T06 | 日期边界 | 不早于2026-10-30、不晚于今日 | 不可选日期禁用；输入非法日期时仍有明确报错 |
| UX-T07 | 单次1年跨度 | 起始日加1个日历年为不包含的右边界，结束日须早于它；2月29日起按次年3月1日为右边界 | 提供「自定义范围最多1年，含首尾日；全部可查看完整历史」帮助说明，依PRD处理闰年 |
| UX-T08 | 校验失败 | 就近显示日期错误，不清空用户输入 | 不发起查询；旧结果继续标明原生效日期，导出保持禁用直至取消或成功查询 |
| UX-T09 | 范围查询中 | 结果区加载，选择区反映目标条件 | 不把旧数值标成新范围；较早查询不得覆盖新结果 |
| UX-T10 | 跨日刷新 | 今日／昨日／近7天／全部按新的今日重算，自定义维持日期 | 结果实际范围与截至时间同步更新 |

日期校验文案见第10节。业务时间统一北京时间，统计截至时间不使用用户设备其他时区。

## 7. 导出UX需求表

| UX编号 | 阶段／模块 | 设计要求 | 操作约束／反馈 |
| --- | --- | --- | --- |
| UX-E01 | 可导出 | 成功查询且无未提交日期编辑时启用「导出数据」 | 全0结果可导出；无额外权限勾选或导出配置弹窗 |
| UX-E02 | 范围提示 | 按钮附近帮助信息说明导出当前客服、所选范围全部每日记录 | 不让用户误以为只导出当前页；历史累计单独包含在汇总信息中 |
| UX-E03 | 文件生成中 | 按钮变为「导出中」，在详情操作区下方展示非模态任务反馈 | 显示「文件生成中，请稍候」及本次实际范围；无真实进度不展示虚构百分比 |
| UX-E04 | 生成期间控件 | 禁止再次导出、切换日期及刷新；允许每日翻页和页面离开 | 禁用状态提供原因「导出中，暂不可修改查询条件」；不强制用户等待 |
| UX-E05 | 生成成功 | 提示「文件已生成」并尝试下载，保留「下载文件」入口 | 解除日期与刷新限制；下载入口绑定本次文件，不混用随后新查询条件 |
| UX-E06 | 下载未触发 | 用户可再次点击「下载文件」 | 不因浏览器未触发下载而重复生成任务 |
| UX-E07 | 生成失败 | 明确错误并提供「重新导出」 | 保留条件与成功统计结果，解除控件限制；结果失效则要求先刷新 |
| UX-E08 | 离开／切组织 | 允许直接离开；不新增任务中心 | 旧任务不得在其他客服或新组织页面触发下载；返回可重新查询导出 |
| UX-E09 | 文件信息 | 文件为.xlsx，名称含组织、客服编号、实际起止日期与生成时间 | 统计截至时间与生成时间区分，名称不合法字符替换 |
