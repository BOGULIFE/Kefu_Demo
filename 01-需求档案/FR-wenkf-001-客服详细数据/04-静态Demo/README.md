# FR-wenkf-001 静态UX设计Demo

交付文件为 `FR-wenkf-001-客服详细数据Demo.html`，样式和脚本全部内嵌。可单独发送此文件，接收方双击即可离线打开，保留日期筛选、分页、状态演示及示例Excel导出。

`index.html`、CSS与JavaScript文件保留为维护源文件；修改源文件后需重新生成独立HTML交付文件。

## 页面及操作

- 默认打开客服列表，延续参考截图的暖白背景、橙色操作、深色文字、细边框、状态标签及后台导航。
- 在「今日接待人数」前查看「累计接待」；「操作」列保留调整容量／只读表现，并增加「详细数据」。
- 点击详细数据进入对应客服独立详情，支持全部、今日、昨日、近7天和自定义日期、每日记录分页、刷新及示例Excel导出。
- 返回列表保留原搜索、状态选项和滚动位置。调整容量仅修改本地演示数据，刷新浏览器恢复初始值。
- 右下角「原型演示」为演示辅助入口，可切换加载、全0、查询失败、翻页失败、结果失效、无权限、客服不可访问等状态，并演示下一次导出失败；该入口不是产品功能。

## 演示数据说明

- 当前日期固定为2026-11-19，历史起点为2026-10-30，默认21条日期记录，每页20条；第2页的0值日期可验证无数据日保留规则。
- 数据全部为本地生成的模拟数据，不连接后台，不代表截图中实际历史业务数据。
- Excel为真实可下载的示例`.xlsx`，含「汇总信息」「每日数据」两张表，均使用当前成功查询的模拟数据。文件名及汇总页标明演示数据，不是生产数据导出。
- 导出模拟生成等待和控件锁定；导出完整查询范围，不仅是当前页。统计截至时间及文件生成时间均为固定演示时间。
- 页面不修改真实权限、组织或客服资料。无权限及导出失败由演示辅助入口模拟；现有菜单和账号操作仅提示其属于原有功能。
- 详情使用手动刷新；列表的更新文字用于还原原页面，本原型不自动轮询。

## 审阅重点

1. 历史累计与所选日期汇总是否易于区分。
2. 日期选择、导出、每日记录入口与布局是否符合使用习惯。
3. 处理中与已完结工单说明是否清楚；三个工单指标不做相加总计。
4. 页面风格、配色和信息密度是否延续现有后台。

本目录为第4步静态交互原型，不包含生产接口、权限实现、持久化存储或真实异步导出服务。
