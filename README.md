# 在线客服-右豹 · 产品需求交付档案

双击根目录 `index.html` 打开需求交付中心，也可通过本地HTTP服务打开。各需求按用户确定的编号归档，不自行编定新编号。

## Demo 汇总入口

- [在线查看需求交付中心](https://bogulife.github.io/Kefu_Demo/)
- [交付中心 HTML 源文件](./00-交付门户/index.html)
- [下载完整交付包](./03-交付打包/右豹在线客服-需求交付.zip)

点击在线交付中心即可查看 Demo 汇总、场景导航及业务流程，无需下载。也可下载完整交付包并解压后，双击根目录 `index.html` 离线查看。

交付中心通过 GitHub Pages 从 `main` 分支根目录发布；后续更新发布分支后，页面会自动重新部署。

## 后续新增需求

1. 先向需求方询问编号，在 `01-需求档案` 中建立「需求编号-需求简称」目录。
2. 按本次相同结构建立各阶段文件夹，每次只产出被授权的阶段，未进入阶段可暂不创建文件夹。
3. 在 `00-交付门户/requirements.js` 中登记需求，文档及Demo路径相对于门户文件夹配置。
4. 需求自己的页面预览放在该需求的 `05-预览图`；交付门户通用截图放在根目录 `02-交付预览`。
5. ZIP与导出样例放到 `03-交付打包`，不要混在源文件目录；发布包排除打包目录本身以避免递归打包。

当前已接入FR-wenkf-001「客服累计接待与详细数据」及FR-wenkf-002「用户提交工单与统一工单处理」（管理后台、移动端H5）。FR-wenkf-002已纳入交付中心，合并到main后由GitHub Pages部署。现有ZIP仍为早期交付包，尚未包含FR-wenkf-002；本次请使用在线入口或下载仓库源码查看完整内容。状态变更仅在浏览器本地保存，不代表实际研发进度；所有原型数据与导出样例均为模拟数据。
